# Social Media Content Archive
A comprehensive archive of my technical content shared across LinkedIn, Twitter/X, and Medium as a Data Analyst who builds and runs my own homelab to practice the infrastructure behind real-world data and analytics workloads.

## About This Repository
This repository serves as a permanent record of all technical posts, insights, and knowledge-sharing content I create on social media platforms. Each post represents real learning experiences from hands-on analytics work, homelab projects, and self-hosted data infrastructure.

**Why this exists:**
- **Centralized archive** - All social media content in one searchable location
- **Learning documentation** - Track my technical growth and evolving understanding
- **Content backup** - Preserve posts that might otherwise be lost on social platforms
- **Portfolio showcase** - Demonstrate consistent technical communication skills as a data analyst
- **Easy reference** - Quick access to concepts, commands, and solutions I've shared

## What You'll Find Here
This archive contains posts covering the systems that data and analytics work runs on, learned and tested in my homelab:
- **Networking for Data Systems** - OSI model, TCP/IP, subnetting, VLANs, firewalls, VPNs, and how data moves between systems
- **Security & Data Protection** - Encryption, TLS, KMS, hashing, digital signatures, secrets management
- **Containers for Data Workloads** - Docker and Kubernetes for running notebooks, pipelines, and databases reproducibly
- **Cloud Data Infrastructure (AWS & Azure)** - IAM, S3 storage, lifecycle and replication, managed identities
- **Storage & Databases** - iSCSI/NFS, PostgreSQL HA, backups, and keeping analytical data safe and recoverable
- **Linux for Analysts** - Commands, troubleshooting, and shell workflows for data work
- **Homelab & Data Science Workloads** - Self-hosted tools, automation, and career insights from running my own environment

Each post includes the original content exactly as shared on social media, along with metadata like posting date, platform, and relevant topics.

## Content Formats
**LinkedIn posts** are short, conversational-technical posts (2-5 sentences per paragraph) - reads like a war story or a lesson learned, often ending with a question to invite discussion.

**Twitter/X threads** are numbered, punchy thread format - the same idea as the LinkedIn post, compressed into short, staccato entries.

**Blog posts** are long-form, tutorial-style articles with structured headers, code examples, and in-depth walkthroughs.

Same topics, different approaches - each platform serves a unique purpose in building my professional presence.
