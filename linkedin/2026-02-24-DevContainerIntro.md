Most developers waste hours setting up their environment on every new machine.

I spent time building a system that eliminates that problem entirely.

Two repos. One command. Fully configured environment anywhere.

Here's how it works:

1. dotfiles repo manages everything personal via chezmoi, applied on any machine automatically.
2. DevContainer repo handles project-specific tools via mise, spun up through DevPod.
3. One bootstrap command pulls it all together on bare metal or inside a container.

The result? Going from a fresh machine to a fully working dev environment without a single manual step.

The part that made it click was separating concerns properly. Personal tools belong to you. Project tools belong to the team. Mixing them creates chaos.

If you're still manually installing tools after every reinstall, you're doing it the hard way.

The full setup is documented on my GitHub: github.com/AhsanRahat12
