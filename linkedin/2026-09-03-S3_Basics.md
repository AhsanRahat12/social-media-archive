One of the most fundamental services and concepts to learn, that is heavily used in the real world and for any certifications exam is the S3 bucket.

What is S3? It is AWS's object storage service. Whenever we think of storing objects in AWS, S3 should be your first and default place to start. It is regionally resilient by default and thus can withstand and be resilient through an AZ failure.

There are however instances when S3 is not the right resource. S3 is not suitable for file based or block based storage. We cannot boot from nor mount S3 based storage systems.

There are of course more complexities and a lot more to S3, but if you start your S3 learning journey with this mental model, you will be in a good place!!
