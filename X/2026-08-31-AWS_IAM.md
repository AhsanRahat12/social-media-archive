1/ Been heads down the past few weeks, but I'm back with what I've been learning: AWS. Sitting the SAA exam soon. First thing I want to share: IAM.

2/ What is IAM? It controls who's allowed into your AWS account and what they can do once inside. Very security focused by design.

3/ Nothing is allowed by default, except root. Root sits outside IAM's normal rules and always has full access. Everyone else needs explicit permission or they're blocked.

4/ 3 identity types: users, groups, roles. Resources can carry their own policies too. All of it gets pooled together before AWS decides anything.

5/ The rule: explicit deny, explicit allow, implicit deny.
Deny anywhere = blocked.
No deny + explicit allow = granted.
Neither = blocked by default.
