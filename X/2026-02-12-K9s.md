# X Post - k9s Discovery

I'm glad I started with kubectl before discovering k9s.

Weeks of running kubectl commands manually built my foundation. Now k9s is my productivity multiplier.

What k9s gives me:

✅ `:pods`, `:deploy`, `:service` for instant navigation
✅ 'l' for logs, 's' for shell, 'y' for YAML
✅ All commands on top right corner

Debugging went from 5-6 kubectl commands to keyboard shortcuts. Saves me 20-30 min daily.

The approach: Learn kubectl first. Then use k9s for speed.
