Hubs and switches seems basic. Understanding the difference teaches you how to think about network performance and security from day one.

Hub: receives a signal and blasts it out of every port. Every device sees every packet. A privacy nightmare and a performance bottleneck in one box.

Switch: learns which device lives on which port. Traffic goes to exactly one destination. Everyone else sees nothing.

The result:
→ Each port gets its own collision domain
→ Network scales without slowing everyone down
→ Traffic is private by default

The hub didn't lose because it broke. It lost because the switch did everything better.

These are the fundamentals that make everything else click.
