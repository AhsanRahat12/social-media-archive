1/ One of the most fundamental services to learn for real world AWS workflows and for any cert: S3.

2/ What is S3? AWS's object storage service. Whenever you're storing objects in AWS, S3 should be your first and default place to start.

3/ It's regionally resilient by default, can withstand and stay resilient through an AZ failure.

4/ There are instances when S3 isn't the right fit though. It's not suitable for file based or block based storage. You can't boot from it or mount it.

5/ There's more complexity and a lot more to S3 than this, but start your learning journey with this mental model and you'll be in a good place!!
